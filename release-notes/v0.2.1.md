# Wizardry 8 한국어 패치 v0.2.1

Fan Patch 1.28 **build 6735 전용** 수정 릴리스입니다.

## 수정 내용

- `Wiz8_v128.exe` 실행 시 Launcher 1.6 대신 게임이 바로 시작되던 문제 수정
- 내부 고정 리소스와 충돌하는 두 번째 `Original` 문자열 패치 제외
- 퀘스트 저널 기록 333문장(실제 337개 슬롯) 한국어화
- 저널 번역에 필요한 굴림 기반 한글 글리프와 EXE 문자 매핑 갱신

## 검증

- Launcher 1.6 창 표시 확인
- `FACT.DBS` 807개 레코드와 337개 저널 슬롯 검증
- 저널 필드 외 변경 바이트 0건
- EXE/DLL PE 체크섬 정상
- 배포 파일 237개 SHA-256 검증

## 설치 주의

- 먼저 Wizardry 8과 Fan Patch 1.28 build 6735를 설치하세요.
- 압축의 `Patch Files` 내용을 게임 폴더에 덮어씁니다.
- 런처 언어는 **ENG**를 사용하세요. `KOR` 외부 로캘은 사용하지 않습니다.
- v0.2.0 사용자는 v0.2.1을 그대로 덮어써도 됩니다.
- build 6709 사용자는 기존 v0.1.0 릴리스를 사용하세요.
