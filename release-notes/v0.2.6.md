# Wizardry 8 한국어 패치 v0.2.6

Wizardry 8 **1.24** 및 Fan Patch **1.28 build 6735**용 대화 토픽 입력 보조 릴리스입니다.

## 변경 내용

- NPC가 실제로 인식하는 영문 대화 토픽을 한국어 번역 뒤에 `한국어( English )` 형식으로 병기했습니다.
- 영문 토큰 주위에 공백을 두어 더블클릭 입력 시 조사와 괄호가 함께 선택되는 문제를 줄였습니다.
- `RUMORS`/`RUMOURS`, `SHIP`, `MESSENGER`처럼 해당 NPC 스크립트에서 확인된 트리거만 병기했습니다.
- 두 대상 버전 모두 139개 NPC 스크립트가 변경되었습니다.

## 제한 사항

- 대화창에서 영문 토큰을 더블클릭해 입력하는 보조 방식입니다. 한국어 토픽을 영문 내부 키워드로 자동 변환하지는 않습니다.
- 기존 세이브의 `[소문]` 같은 항목은 자동 변환되지 않습니다. NPC에게는 새로 입력한 `Rumors`/`Rumours`를 사용하세요.
- 닫는 큰따옴표 표시는 게임 내에서 확인이 필요한 실험적 수정입니다.

## 검증

- 두 ZIP의 압축 구조를 검사했습니다.
- 두 패키지 모두 기준 v0.2.5 대비 142개 파일이 변경되었고, 그중 139개는 NPC 스크립트입니다.
- 나머지 3개 변경 파일은 안내문과 SHA-256 목록입니다.
