# Wizardry 8 한국어 패치 v0.2.0

Fan Patch 1.28 **build 6735 전용** 업데이트입니다.

## 포함 내용

- 본편 UI와 메시지, 플레이어 음성 자막 한국어화
- NPC 대화와 아이템·주문 설명 한국어화
- 아이템 이름 819개 한국어화
- Fan Patch 1.28 build 6735 추가 옵션 문자열 한국어화
- 굴림 기반 3,299 슬롯 비트맵 글꼴과 한국어 문자 매핑
- 플레이어 대사창 및 MSG 오프셋 수정
- 아이템 이름 필드와 아이콘 데이터 경계 검증

## 설치 주의

- 먼저 Wizardry 8과 Fan Patch 1.28 build 6735를 설치하세요.
- 압축의 `Patch Files` 내용을 게임 폴더에 덮어씁니다.
- 런처 언어는 **ENG**를 사용하세요. `KOR` 외부 로캘은 사용하지 않습니다.
- build 6709 사용자는 기존 v0.1.0 릴리스를 사용하세요.

자세한 내용은 압축 안의 `README_KO.txt`를 확인하세요.
