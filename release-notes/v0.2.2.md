# Wizardry 8 한국어 패치 v0.2.2

Fan Patch 1.28 **build 6735 전용** 가독성 개선 릴리스입니다.

## 변경 내용

- 한글 비트맵 글꼴을 Noto Sans KR Light(300) 기반으로 교체
- 8×7 초소형 글꼴은 프리텐다드로 유지해 획 손실 방지
- `Bo`, `Hayai Bo`, `Zatoichi Bo` 아이템명을 `장봉`, `하야이 장봉`, `자토이치 장봉`으로 교정
- 기존 플레이어 대사, 저널, 아이템 이름 및 Fan Patch 6735 번역 유지

## 검증

- 테스트 완료된 Noto Light 글꼴 13개와 릴리스 글꼴의 SHA-256 일치
- 배포 파일 237개 SHA-256 검증
- ZIP 무결성 검사 통과
- `Wiz8_v128.exe`와 `Wiz8.dll` PE 체크섬 정상
- 아이템 79~81번 이름과 나머지 레코드 구조 검증

## 설치 주의

- 먼저 Wizardry 8과 Fan Patch 1.28 build 6735를 설치하세요.
- 압축의 `Patch Files` 내용을 게임 폴더에 덮어씁니다.
- 런처 언어는 **ENG**를 사용하세요. `KOR` 외부 로캘은 사용하지 않습니다.
- v0.2.0 또는 v0.2.1 사용자는 v0.2.2를 그대로 덮어써도 됩니다.
- build 6709 사용자는 기존 v0.1.0 릴리스를 사용하세요.
