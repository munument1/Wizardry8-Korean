# Wizardry 8 한국어 패치 v0.2.3

Fan Patch 1.28 **build 6735 전용** NPC 대사 출력 수정 릴리스입니다.

## 변경 내용

- NPC/RPC 대사가 영어로 대체되거나 대화가 멈추던 문제 수정
- `Wiz8_v128.exe`의 NPC NSF UTF-16 문자열 변환에 한국어 로캘 적용
- CP949 변환에 필요한 출력 버퍼 크기 확대
- 기존 UI, 지역 메시지, 플레이어 음성 자막, 저널, 아이템 및 NPC 번역 유지

## 검증

- 짧은 한국어 NPC 대사 정상 출력 및 대화 진행 확인
- 긴 한국어 NPC 대사 정상 출력 및 대화 진행 확인
- 서로 다른 NPC의 대사 정상 출력 확인
- 배포 파일 237개 SHA-256 검증
- ZIP 무결성 검사 통과

## 설치 주의

- 먼저 Wizardry 8과 Fan Patch 1.28 build 6735를 설치하세요.
- 압축의 `Patch Files` 내용을 게임 폴더에 덮어씁니다.
- 런처 언어는 **ENG**를 사용하세요. `KOR` 외부 로캘은 사용하지 않습니다.
- v0.2.0~v0.2.2 사용자는 v0.2.3을 그대로 덮어써도 됩니다.
- build 6709 사용자는 기존 v0.1.0 릴리스를 사용하세요.
